# Support

## Integration issues

Use this repository's issue tracker for reproducible problems or feature requests involving the StoryChief package for Xperience by Kentico. Include the package version, Xperience version, .NET version, webhook event, relevant sanitized logs, and reproduction steps.

Never include signing keys, Xperience license keys, credentials, customer content, or private URLs.

## StoryChief product support

For StoryChief accounts, workspaces, billing, or product behavior, use the [StoryChief support channels](https://help.storychief.io/en/articles/2731489-contact-storychief-support).

## Xperience support

For Xperience installation, licensing, content modeling, or platform behavior outside this integration, use Kentico's official documentation and support channels.

This repository is maintained by StoryChief and is not covered by Kentico's support policy unless Kentico explicitly states otherwise.
