# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-19

First stable release of `StoryChief.Xperience`, incorporating the features and fixes validated in the `1.0.0-rc.1` and `1.0.0-rc.2` release candidates.

## [1.0.0-rc.2] - 2026-08-19

### Fixed

- Repeated locked publish updates no longer fail when the Xperience page is already published.

## [1.0.0-rc.1] - 2026-08-19

### Added

- Authenticated StoryChief publishing webhook with signed connection-test responses.
- Xperience page creation, draft updates, publishing, URL synchronization, and deletion.
- Configurable StoryChief-to-Xperience field mapping.
- Multilingual page variants with explicit language mappings.
- Reusable Content Hub cover-image assets with alternative text and lifecycle cleanup.
- Native taxonomy mapping for tags, primary categories, and categories, including localized titles and stable managed-tag reuse.
- Buildable example application, automated tests, contributor guidance, support policy, and security policy.
