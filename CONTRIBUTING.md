# Contributing

Thank you for helping improve StoryChief for Xperience by Kentico.

## Before opening an issue

- Search existing issues and pull requests for related work.
- Use the security process in [SECURITY.md](./SECURITY.md) for vulnerabilities.
- Use StoryChief support for account, workspace, billing, or product questions.

## Development workflow

1. Fork the repository and create a focused branch.
2. Follow the [contributor setup guide](./docs/Contributing-Setup.md).
3. Add or update tests for behavior changes.
4. Update documentation for public APIs, configuration, or user-visible behavior.
5. Run formatting, build, and tests before opening a pull request.
6. Complete the pull request template and link any related issue.

Keep changes focused and avoid committing credentials, Xperience license keys, customer content, database backups, or generated build output.

## Review and licensing

Maintainers may request changes before merging. By contributing, you agree that your contribution is licensed under this repository's [MIT License](./LICENSE.md).

All contributors must follow the [Code of Conduct](./CODE_OF_CONDUCT.md).
